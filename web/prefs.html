Preferências

Idioma do áudio

Vale para os pedidos e para o "Assistir". A decisão fica com o Radarr (filmes) e o Sonarr (séries e animes), com estas regras. Série ou anime em "obrigatório" sem versão dublada em nenhuma fonte: o cartão pergunta se pode instalar o legendado (e troca pelo dublado se ele surgir). Entre as legendadas, as com legenda em português vêm primeiro.

Qualidade

Vale para os pedidos e para o "Assistir". No "Assistir", uma versão com poucas fontes perde para uma bem semeada, e o player sugere uma versão mais leve se o download não acompanhar.

Histórico de outros serviços

Alimenta o "Para você" com o que você assiste fora daqui.

Netflix

Na Netflix, em Conta → Perfil → Atividade de visualização, use "Baixar tudo" e envie o arquivo aqui. Pode enviar de novo quando quiser atualizar (substitui o anterior).

Crunchyroll

Histórico completo, de uma vez: arraste este botão para a barra de favoritos do navegador (no computador) → Histórico Crunchyroll → Anubis. Depois abra crunchyroll.com (logado) e clique no favorito: ele lê o seu histórico pelo próprio site e baixa crunchyroll-historico.json. Envie o arquivo aqui. A senha não passa pelo Anubis.

Daqui para a frente (opcional): com a extensão MAL-Sync ligada a uma conta do AniList, o que você assiste na Crunchyroll pelo navegador vai sozinho para o AniList. Aqui, o nome de usuário do AniList (lista pública).
